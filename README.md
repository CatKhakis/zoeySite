# LarkBarks

Powered by [Pelican](https://getpelican.com) - Icons by [Lucide](https://lucide.dev) - Colors by [Catppuccin](https://catppuccin.com)


### commands to run locally:
```virtualenv ~/virtualenvs/pelican

source bin/activate
cd ~/Documents/VSCode/zoeySite

make devserver
```
